# lp-template

Instagram特典配布LPのベーステンプレートです。`index.html` 1ファイル（CSS・JS内蔵）＋ `assets/` で完結します。
[AI絵本販売LP](https://ryooh18-byte.github.io/ehon-amazon-lp/) をもとに、毎回同じ部分を「固定」、テーマごとに変わる部分を「空欄」にしています。

## 基本の流れ

1. このテンプレートを新しいリポジトリにコピーする（例：`◯◯-lp`）
2. **台本**（下記の項目）を用意して、`index.html` の空欄に流し込む
3. 台本の画像を `assets/` に入れる
4. `git push` → GitHub Pagesで公開

台本だけ用意すれば、固定部分の作業は不要です。

## 台本に必要なもの（＝毎回変わる部分）

| 場所 | 内容 |
|---|---|
| ページタイトル・説明文 | `<title>` と meta description（検索結果用） |
| タイトル（H1） | 1行目＋強調キーワード（例：ChatGPT絵本販売 / **完全ガイド**） |
| 概要 | 「◯◯とは」＋1文の説明＋ポイント3つ |
| STEPS | 見出し・リード文／各STEPの見出し・本文・手順・プロンプト・コツ・注意・画像・表／補足カード |
| 締めの一言 | 「ここまで読んでくださり…」に続く1文 |

STEPは、`index.html` のコメントにある部品（STEPカード／プロンプト（折りたたみ）／チェックリスト／補足ボックス／注意・コツ／画像／表）を組み合わせて作ります。

## 固定部分（触らなくてOK）

- 上部のプロフィールリンク（Instagram）
- 特典バナー（`assets/free-gift-banner.png`）※ページ内2箇所（冒頭・最後）
- お礼＋自己紹介（ペルソナ文）
- 締めのMESSAGE（AIワーク0-1達成スタートブックの案内文・LINEボタン）
- 最後のCTA、固定フッターの免責、スマホ下部の固定ボタン
- LINE登録リンク（`https://x.gd/z6wxZ`）は全箇所に直接入っています。変更する場合は `index.html` 内の `x.gd/z6wxZ` を一括置換してください。
- 全体のデザイン（CSS）、プロンプトの「コピーする」ボタンの動作

## ファイル構成

- `index.html` … LP本体
- `assets/kumi-profile.png` … プロフィール写真
- `assets/free-gift-banner.png` … 特典バナー（LINEリンクつき）
- `assets/` … このLP専用の画像（STEPの説明画像など）もここに置く
